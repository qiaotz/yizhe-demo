# 演示范围与数据说明

## 适合用来了解什么

这份演示面向查看简历与项目作品的访客。打开链接后可以直接进入核心学习流程，无需邀请码、登录或填写个人信息。

建议按页面指引依次体验：选择学习卡 → 预习检测 → 知识课堂 → 课堂微测 → 做题验证 → 错因复盘 → 间隔重做 → 主动回忆。为展示改错环节，流程包含明确提示的错误作答示例；间隔重做省略实际等待。

## 能力范围

| 能力 | 本演示的行为 |
| --- | --- |
| 知识卡与课堂 | 展示精选知识点与相应结构化内容 |
| 检测与作答 | 用固定示例题呈现选择、提交、反馈及页面衔接 |
| AI 解析 | 呈现标明为预置示例的解析，不发送真实模型请求 |
| 错因建议 | 按示例错因呈现建议，可体验核对与编辑 |
| 重做与主动回忆 | 体验再次作答、答案揭示与回忆反馈 |
| 学习进度 | 保存当前浏览器中的演示进度 |
| 完整内测账号、云端同步 | 不提供 |
| 付费、实时 AI、录音与上传 | 不提供 |
| 完整题库与课程视频 | 不提供 |

择校、院校招生数据、复试、AI 面试和公开社区已退出医者产品计划，也不属于演示的后续扩展范围。

## 本地状态与重置

演示状态只服务于当前浏览器的体验，不写入医者正式数据库，也不消耗真实用户的 AI 额度。不同浏览器或不同浏览器用户配置各自保存状态；同一浏览器配置中的多个标签页可能共享同一份本地状态。

重新开始用于重置演示流程。清除站点存储也会移除该浏览器保存的演示进度。演示状态不跨设备同步，不应作为正式学习记录使用。

## 示例与源码

本仓库从现有 H5 工程中提取页面、组件、样式、流程状态与浏览器适配代码，并加入公开演示所需的本地数据与入口约束。它是一份用于展示的精选源码快照，不是完整生产工程，也不包含生产工程的提交历史。

AI 结果是预先准备的示例，页面中的即时反馈不代表在线模型生成速度。示例题与知识卡用于展示产品交互，不代表完整内容库的规模或审核覆盖。演示没有用户增长、学习效果或性能统计的证明作用。

课程视频、完整题库、用户导出、云端凭据和内部运维材料不在公开范围。仓库目前未指定开源许可证；第三方依赖及其权利声明按各自许可证处理。
