# 医者 · 医学学习流程演示

医者是一款围绕医学知识学习与错题复盘的小程序。本仓库展示其中可在浏览器体验的核心流程，以及经过整理的 H5 前端源码，供简历展示与技术交流。

**无需注册或邀请码。** 访客可以从一张学习卡开始，完成预习检测、知识课堂、做题验证、错因复盘、间隔重做与主动回忆。AI 解析与错因建议使用明确标注的预置示例。

**[在线体验](https://qiaotz.github.io/yizhe-demo/) · [GitHub 仓库](https://github.com/qiaotz/yizhe-demo)**

## 体验什么

| 环节 | 可观察的产品设计 |
| --- | --- |
| 学习卡与预习检测 | 先确定学习内容，再用问题检查已有理解 |
| 知识课堂与微测 | 将核心结论、机制、解题路径与病例线索组织在同一知识卡中 |
| 做题验证 | 用新题检查知识应用，并演示进入错题流程 |
| 错因复盘 | 选择错因，核对并编辑 AI 示例建议，确认自己的复盘 |
| 间隔重做与主动回忆 | 再次作答、先回忆后揭示答案，记录本地体验进度 |

演示将间隔等待压缩为立即可继续，以便在一次访问中看完整条学习流程。当前浏览器中的演示进度可以重置；不会创建内测账号，也不会写入正式学习记录。

## 值得阅读的实现

- **复用真实页面组织学习流程：** [路由与演示数据适配](src/services/onboarding-guide.js) 将相同知识点贯穿多个页面。
- **独立的公开体验入口：** [演示入口](src/pages/showcase/index.js) 与 [访问及重置控制](src/services/portfolio-demo.js) 管理免登录体验的边界。
- **状态与内容分离：** [本地体验状态](src/services/product-tour.js) 管理当前环节与进度，[精选示例内容](src/services/onboarding-demo-data.js) 提供独立的数据输入。
- **结构化内容展示：** [知识课堂](src/pkg-course/classroom/index.js) 承接知识卡、局部解析与课堂检测。
- **让学习者参与复盘：** [错因页面](src/pkg-question/wrong-case/index.js) 将错因选择、建议核对与确认串联起来。
- **浏览器适配：** [H5 运行时适配](h5-runtime-adapters.js) 支持小程序页面在 Web 环境中的交互。

## 本地运行

本仓库采用 JavaScript、WXML、WXSS 与 weapp-vite / Vite。运行前按 [package.json](package.json) 的 `engines` 安装对应 Node.js 版本。

```bash
npm ci
npm test
npm run build
npm run preview
```

在浏览器打开终端打印的本地地址。静态构建不需要腾讯云账号、数据库、邀请码或模型密钥；构建脚本和输出路径以 [package.json](package.json) 为准。`npm test` 用于运行仓库检查，不能替代浏览器中的完整体验验收。

推送到 `main` 后，[发布工作流](.github/workflows/pages.yml) 会完成测试与构建并自动发布到 GitHub Pages；[检查工作流](.github/workflows/verify.yml) 同时对推送和 Pull Request 执行测试与构建。

## 产品架构与演示边界

完整产品包含微信小程序、H5、Vue 管理平台，以及 NestJS、Prisma、MySQL 与云端 API。本仓库只提供 H5 演示所需的精选前端源码；生产后端与管理平台通过文档说明。

真实产品的 AI 采用完整应答流程；本演示展示预先准备的输出与交互，不执行实时模型推理。公开演示不能用于证明生产 AI 的响应耗时、额度结算、内容覆盖或上线后的学习效果。

## 首次体验引导视频

入口复用项目已有的 V5 历史引导视频（约 34 秒）及原始封面，点击后才播放。开始体验会开启新一轮演示；跳过介绍直接进入预习，也可继续已保存的进度。历史视频部分界面与当前演示不同。视频随静态站点打包，同源加载，不连接正式 API；不包含完整课程视频库。
