# H5 导航修复 · 2026-09-22

## 复现与原因

线上版本从预习页点击原生底栏“上课”，会回到项目介绍。代理 Tab 页与详情页之间的生命周期切换被旧引导当成退出，留下 exitToOverview 标记，下一次跳转被改写为首页。课堂、做题和改错属于非 Tab 详情页；复习答题也会主动隐藏原生底栏，因此自由浏览时缺少稳定的切换入口。

## 修改

- 旧 Tab 地址直接映射到对应的公开演示环节，在导航前激活正确的本地示例。
- 公开演示中的页面隐藏、卸载不再隐式结束引导；“退出体验”仍返回介绍页，并保留继续体验入口。
- 增加独立的五环节导航，覆盖章节、预习检测、课堂、做题、归因、重做、主动回忆和结果页；介绍页不显示底栏。
- 页面内容与导航占用独立区域，提交按钮、AI 面板及滚动内容留在内容区域内，避免相互遮挡。沿用现有图标，无新增依赖或图片。
- 导航跟随页面生命周期、浏览器返回及地址变化更新高亮。原生按钮支持键盘操作。

## 实际检查

- `npm test`：22 / 22 通过，含新增的代理 Tab 直达、隐藏/卸载不退出、详情页导航归属回归检查。
- `npm run build`：通过；静态输出 80 文件、约 1.28 MiB，API 与远程媒体隔离检查通过。仍有既有的大于 500 kB 分块提示。
- 浏览器：五环节连续手动切换均到达正确页面，导航可见且高亮匹配。
- 浏览器：键盘 Enter 切换、返回课堂、刷新详情页、桌面侧栏快捷入口、明确退出与继续体验均通过。
- 实际操作：选择学习卡→预习检测→提交→进入课堂；做题→提交→归因→预置 AI 建议→确认→重做→提交→主动回忆→自评→结果页。操作区与导航分离。
- 已检查 320×740、390×760、768×1024、1068×782、1280×720、1440×900 的截图；320 宽无横向溢出，导航按钮高度 53px。1280×720 留有改前、改后同视口截图。
- 浏览器检查期间未记录到控制台 warning / error。

## 边界

以上为执行与自查结果，不代表用户批准设计。真机微信内置浏览器、软键盘弹出后的可视高度尚未验证。课堂 AI 解析与课堂微测全链路本轮未重新走完；本轮验证的是页面导航与所列操作。演示仍使用精选示例与预置 AI 输出，不连接生产后端，也不等于完整产品。
